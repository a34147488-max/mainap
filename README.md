# VK COIN Exchange

Статический прототип интерфейса обмена VK COIN.

## Запуск

Открой `index.html` в браузере. Для публикации можно включить GitHub Pages в Settings → Pages и выбрать ветку `main`, папку `/ (root)`.

## Важно

- Калькулятор и интерфейс заявок работают в браузере.
- Заявки сохраняются локально в `localStorage` конкретного устройства и не отправляются оператору.
- Telegram username определяется только при запуске внутри Telegram Web App и при наличии доступного профиля.
- Подтверждение платежа, проверка перевода монет, админ-панель и автоматические выплаты не реализованы. Для реального запуска нужен сервер/API, база данных и безопасная проверка Telegram initData.
- Не публикуйте секретные ключи, банковские данные пользователей или токены бота в клиентском коде.
